# GLaDOS Sounds

These boot sounds are downloaded by `scripts/download-sounds.sh` rather than stored in the repository.

## Files

| File | Purpose | Source |
|---|---|---|
| `powerup01.wav` | First power-up sound | https://i1.theportalwiki.net/img/d/de/Announcer_wakeup_powerup01.wav |
| `powerup02.wav` | Second power-up sound | https://i1.theportalwiki.net/img/a/a1/Announcer_wakeup_powerup02.wav |
| `glados_wakeup.wav` | GLaDOS wake-up sound | https://i1.theportalwiki.net/img/3/34/GLaDOS_chellgladoswakeup01.wav |

The installer downloads these files into `/opt/glados/sounds/`.
