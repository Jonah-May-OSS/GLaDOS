# Display Assets

The `aperture_sprite.png` asset is derived directly from the supplied `Aperture.h` bitmap data. The source contains one complete 240×240 aperture (`Aperture0`) and eight individual 240×240 blade masks (`Aperture1`–`Aperture8`).

The sprite stores nine 240×240 monochrome composite frames: the complete aperture followed by progressively opened states built from those source masks.
