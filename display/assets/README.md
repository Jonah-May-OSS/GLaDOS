# Display Assets

These nine 240×240 monochrome aperture images were converted from the supplied Aperture.h source (Aperture0 through Aperture8).

- aperture0.png is the complete aperture.
- aperture1.png through aperture8.png are the individual aperture-blade frames supplied in the source.
- The display renderer uses frame 0 for idle/wake and the blade frames as animated sequences for listening, thinking, and speaking.

The source file was supplied for this project; preserve any upstream attribution or licensing requirements associated with that source when redistributing the artwork.
